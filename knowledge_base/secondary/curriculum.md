# Ironhack AI Consulting Bootcamp – Curriculum (weekly topics)

Source: Ironhack student platform, course calendar (2026 cohort). Lessons and labs per week.
Note: Week 6 is not included yet.

## Week 1 – Python, AI literacy and first AI APIs
Lessons: Python environment setup, AI literacy, Python review, ML and neural networks fundamentals, generative AI, speech recognition fundamentals.
Labs: programming foundation exercises, data manipulation and JSON handling, sklearn model training and evaluation, API calling to ChatGPT, Whisper speech-to-text implementation.
Extra labs: API calling with JSON, building a simple neural network, comparing Whisper with Google speech-to-text.

## Week 2 – Project 1, project management, prompt engineering and automation
Lessons: generating a small podcast from notes, classical project management (scoping and basics), prompt engineering fundamentals, Python for low-code, automation with Python, AI agent skills.
Project 1: kickoff and deliverables (team project).
Labs: post-project review (stakeholders and real-world scope), prompt engineering lab, refactoring a hacky script into production-ready code ("from hacky script to we could ship this").
Self-guided: exploring the skills ecosystem.

## Week 3 – API integration patterns, RAG and Kanban (Project 2)
Lessons: API and integration patterns fundamentals, integration patterns, RAG introduction, business case for real-world RAG applications, agile management with Kanban, product tips (JTBD, MoSCoW, RICE).
Labs: multi-provider LLM pipeline with fallback ("two brains, zero single point of failure"), reflection skills for coding assistants, chunking strategies for RAG ("slice docs the way Google wishes you would").
Extra lab: RAG with the training wheels off.
Project 2: brief, planning template, evaluation rubric and deliverables (AI content creator with knowledge bases).

## Week 4 – LangChain, RAG pipelines, MCP, agents and n8n
Lessons: LangChain integration, RAG pipeline, MCP (Model Context Protocol) introduction, LangGraph integration, agent fundamentals, n8n introduction.
Labs: chaos agent with tools and judgment, retrieval quality ("first match ≠ right match"), agents that speak MCP, reading documentation ("become the person who reads the docs").
Extra labs: wiring your IDE to MCP, making agents safe, research in / Notion out.

## Week 5 – Advanced n8n, autonomous agents, Scrum and Project 3
Lessons: advanced n8n workflows, autonomous AI systems, agile management with Scrum, review and project preparation.
Labs: Telegram bot with Google Sheets in n8n, architecting a bot someone will pay for.
Extra labs: robust workflows, error triggers, procurement constraints, and n8n vs Python comparisons (RAG pipeline, multi-provider LLM pipeline, data validation and routing, vision product listing, Whisper STT, prompt engineering, chunking strategies).
Project 3: brief, planning template, evaluation rubric.

## Week 7 – EU AI Act, GDPR, ethics, sustainability and evaluation
Lessons: EU AI Act for consultants (roles, GPAI, liability boundaries), compliance and legal for AI consultants, GDPR and the EU data/privacy stack, ethics and responsible AI, green software and sustainable AI, model evaluation, LangSmith, statistical A/B testing for LLM evaluation, agile management with Extreme Programming, business impact.
Labs: classifying an AI product under the EU AI Act, privacy review of a product, GDPR audit of your own and a teammate's project, defending a tech stack's carbon footprint, LLMs grading LLMs, micromanaging agents, data-driven evaluation ("in God we trust, everyone else bring the data").
Extra labs: official green vocabulary, auditing a tech stack, building a human evaluation lab, hacking your LLM.
